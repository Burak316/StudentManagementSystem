# Student Management System

A simple console-based Student Management System developed using C#.

## 🚀 Features

*   **Add students:** Register new students with their unique IDs and names.
*   **List all students:** View a complete list of all registered students and their grades.
*   **Search students by ID:** Quickly find a specific student's details using their ID.
*   **Delete students:** Remove a student from the system.
*   **Update student grades:** Modify the existing grades of registered students.
*   **Calculate average grade:** Automatically compute the class average.
*   **Find the highest grade:** Identify the top-performing student in the system.
*   **Prevent duplicate student IDs:** Ensures every student has a unique identifier.

## 💻 Technologies Used

*   C#
*   .NET 8.0 (Console Application)
*   Visual Studio Community
